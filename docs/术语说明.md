下面是这张符号说明表的中文翻译：

| 符号 | 语言模型术语 | 强化学习术语 | 含义 |
|---|---|---|---|
| \(\rho\) | 提示词分布或数据集 | 初始状态分布 | 提示词或问题的概率分布。 |
| \(x\) | 提示词；问题 | 初始状态 | 从分布 \(\rho\) 中采样得到的一个提示词或问题。 |
| \(y\) | 回答；补全；生成结果；样本 | rollout；轨迹；采样得到的动作序列 | 针对提示词 \(x\) 采样生成的一个回答。 |
| \(y_t\) | token | 动作 | 回答 \(y\) 中生成的第 \(t\) 个 token。 |
| \(y_{<t}\) | 前缀 | — | 位置 \(t\) 之前生成的所有 token，即 \(y_1,\ldots,y_{t-1}\)。 |
| \(\pi_\theta\) | 模型 | 策略 | 参数为 \(\theta\) 的模型。对于给定提示词 \(x\)，它为回答 \(y\) 分配概率 \(\pi_\theta(y\mid x)\)。 |
| \(\pi_\theta(y_t\mid x,y_{<t})\) | 下一 token 概率分布 | 时间步 \(t\) 的策略 | 给定提示词 \(x\) 和先前生成的 token \(y_{<t}\) 时，生成 token \(y_t\) 的条件概率。 |
| \(r(y\mid x)\) | — | 奖励 | 表示采样回答正确程度的标量分数；本作业中取值为 0 或 1。 |
| \(B\) | 每个 batch 中的提示词数量 | — | 每个推理 batch 包含的问题或提示词数量。 |
| \(G\) | 每个提示词的生成数量 | 组大小 | 针对每个提示词采样生成的回答数量。 |
| \(\operatorname{len}(y)\) 或 \(L\) | 回答长度 | horizon（时间跨度） | 一个回答中生成的 token 数量。 |
| \(A^{(i,j)}\) | — | 优势值（advantage） | 经过基线校正和归一化之后，分配给第 \(i\) 个问题的第 \(j\) 个回答的权重。 |

其中几个对应关系尤其重要：

- prompt \(x\) 对应 RL 中的初始状态；
- 每次生成 token \(y_t\) 对应执行一个动作；
- 完整回答 \(y\) 对应一条 rollout/轨迹；
- 语言模型 \(\pi_\theta\) 对应 RL 中的策略；
- advantage \(A^{(i,j)}\) 决定训练时应提高还是降低该回答的概率。

例如，当 \(B=2,\ G=4\) 时，一次推理包含 2 个不同问题，每个问题生成 4 个回答，因此一共得到 8 条 rollout。
